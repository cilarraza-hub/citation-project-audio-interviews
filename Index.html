Audio Interviews

A simple page for storing and previewing audio files used in the citation project.

Place audio files in a dedicated directory (for example audio/) in this repository or host them externally and link here.

Example audio player

Uncomment and update the src attribute to load an audio file from the repository or an external URL.

Notes

  • Keep filenames short, descriptive, and URL-safe (avoid spaces and special characters).
  • If storing large files, consider using a release, Git LFS, or external storage (S3, Google Drive, etc.).
